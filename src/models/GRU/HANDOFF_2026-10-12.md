## 2. 硬规则

1. 助手不做 git commit / push / stash / checkout / tag，owner 自己提交。
2. 永远不改 `AI-TES/data/` 下任何文件。物理缓存等派生数据放 wiki 的 PLAN 目录，不放 data/。
3. 实验室服务器 Python < 3.12：不用嵌套同种引号的 f-string、`dict | dict`、`str.removeprefix`、`hashlib.file_digest`、`match`。本机只有 3.13，所以 ≤ 3.11 的冒烟要在服务器上做一次。
4. 新旋钮五处都要接：`config.py` 读环境变量 → `RUN_NAME_BASE` 标签 → `run_config.json` → `eval_checkpoint.env_from_config / KEYS` → `export_results.leaf_name / family`。少一处 run 会被静默并进 baseline 族。
5. 行为保持：所有新旋钮默认值等于旧行为。唯一有意的数值改动是 H9 的锚最后一步差一修复。
6. 封存：每个 Round 10 run 都 `SEAL_TEST=1`（启动器强制）。测试集只在两个预注册点读：B6（P1 之后，只看 case 70/42/66/67 和 66 案例配对差的区间）和 F11（最后）。其他一切决定在验证集上做。
7. 预注册 `prereg/round10_v3.json` 在 P1 启动后冻结；带是校准出来的，不是 0.05：T_inner 0.02、T_outer 0.05、T_avg 0.08，每个比较再按自身逐文件差额算一次实际带，取大；落在带内写"indistinguishable at n=20"。
8. 范围：只做 GRU（和 LSTM 单元对照）。PINN / 物理损失是另一个组的；DeepONet、TCN、NARX 不做。
